「Webコンテンツ作成」の成果

本テーマについて

個人で運営しているブログサイトと同じくらいのクオリティの個人のWEBページを作れるだけの技術を学び、修了後に実際に作ってみたい。また、その構成やデザインもこだわって作れるぐらいの技術や知識も持ち帰りたい。

プロジェクト課題について

チャンネルとジャンルを選択することで、条件に合った番組のデータを表示させる番組表を制作した。データがない項目には「記載無し」、プルダウンによる選択がどちらか欠けている場合には「検索したいチャンネルとジャンルを両方選択してください」、条件に合うデータが見つからなかった場合には「条件に合う番組は見つかりませんでした」とそれぞれ表示する。また、取得したデータの時刻を見やすい形に変換した後に表示させることや、表の形式で検索結果を表示させることも行なっている。

プロジェクト課題で制作したページ：project.html

数当てゲーム

ページ読み込み時に1~10の数字が設定され、その数字を的中させることが目的のゲーム。テキストボックスの中に数字を入れた後にボタンをクリックすると、その数字が設定させた数字と同じか、または大きいか小さいかを判定する。的中するか3回ボタンを押した時点でゲーム終了。その後にボタンを押した場合は、ゲームは終了している旨を伝えるメッセージを表示させる。

querySelectorとinputの組み合わせで入力された数字を取得後、答えと入力された値の大小関係を調べ、数えられているボタンを押した回数や、これまでに正解したかどうかのboolean型の変数も参照し、if文によって条件に合うコメントに設定する。その後、設定されたコメントをp要素として表示させている。

各授業回の学習事項

第1回 WWWとHTML

基本的なHTML文書の書き方と、リストや見出し、イタリック体や強調の作り方、他文書ファイルへのURLや画像の埋め込み方を学んだ。また、及びHTMLのデバッグは、右クリック→ソースを表示→赤い波線部が無いか確認すると良いということも学んだ。

演習の成果：演習1-4：HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

CSSによる、webページの装飾の仕方が理解できた。javaのメソッドみたいに、自他共に分かりやすいクラス名をつけるように心がけたい。href(URLを埋め込むコマンド)のスペルミスには十分注意すること。

演習の成果：演習2-3：ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

JavaScriptを使い、Webページのコンソール欄に条件を満たすもののみを表示させる方法が理解できた。表示させる際に「グループ名.登録タグ」のグループ名を忘れないよう、またfor-of構文は数字の入る文字が先頭であることの2点に十分注意したい。

演習の成果：演習3-6：オブジェクトの参照

第4回 DOM と JavaScript

ボタンやテキストボックスの配置、それらに操作が加わった場合にWEBページに変更を加える方法が理解できた。今回データを取得する際、「'タグの種類#id'」や「'タグの種類[nameなど="対応するデータ"]'」のシングルクォーテーションやダブルクォーテーションが抜けたために何度もエラーを吐かれたため、以降は十分に注意する。

演習の成果：演習4-10：足し算プログラム

第5回 イベント処理

A.insertAdjacentElement('afterend',B)…Aが終わった後にBを置く、A.insertAdjacentElement('beforeend',B)…Aが終わる前にBを置く

演習の成果：演習5-7：DOMの演習その2

第6回 プロジェクト課題

Ajax通信…ページ全体を再読み込みせずに、ページの一部だけ更新する処理。今回はaxiosというライブラリを使用。データの要求後、ブラウザの別の処理を行い、返ってくるデータの読み取りはイベント処理として行う方式。

工夫点、苦心点、強調点、感想

　プロジェクト課題にて工夫した点は、「表の形式で表示させるようにしたこと」、「データがなかった際にその旨を表示させること」、「空欄の部分に『記載無し』と表示させること」、「時間の表記を見やすい形に変換した後に表示させること」、「プルダウンによる2つの選択が片方でも行われていない際に、両方選択する旨を表示させること」の5点である。
　番組表であるため、必要な情報が見てすぐ分かるように表示させた方が良いと思い、表の形式で表示させるようにした。ボタンが押されるとtd要素やth要素などが追加され、その中身にデータから取得した内容が入るようになっている。
　条件に合うデータが見つからなかった際に、Webページに何も変化がないのは味気ないうえに分かりにくいと思い、前回の検索結果を削除した後に「条件に合う番組は見つかりませんでした」と表示させることにした。同様に、データに空欄の部分があった際に「記載無し」と表示させることにした。If文でdata.listがnullだった場合、データが””だった場青でそれぞれ分岐するようにした。
　データから取得した時間をそのまま表示させた場合、非常にわかりにくい表記となってしまったため、dateオブジェクトによって年月日と時刻をそれぞれ取得して表示させるようにした。また、0分や5分の場合には：00や：05のように表示させるようにもした。取得した分が10未満の際に、0を追加で表示させるようにした。
　データのURLを設定する前に、チャンネルやジャンルが選択されていない際のプルダウンに設定されたvalueの値でないかを判定を行い、設定されてない場合の値だった際に両方選択する旨を表示させるようにした。

　苦心点としては、表の形式にして検索結果を表示させることである。作り始めは開始時刻の項目に全ての内容が入ってしまい、綺麗に表示できていなかった。その原因は、jsファイルで要素を追加する際に、「追加する際に指定する要素」と「それが終わる前後のどちらか」の設定を間違えていたためであった。それに気づくのに時間がかかってしまったが、上手く表示できるようになった。

　感想としては、もう少し細部にこだわる時間を確保できなかったことが残念である。functionにまとめたりif文の外に出したりして、同じ処理を行なっている部分を削除したり、順不同の処理は種類ごとに分けて追記をしやすくしたり、奇数行と偶数行で背景色を変えたり、項目の間に線を入れたり、検索結果同士の隙間を開けたりということを行いたかった。cssに関しては、ファイルを作りコードを書いたものの、実際のページに反映されず、その改善を行う時間すら取れなかった。工夫点の作業に時間がかかりすぎてしまったために時間が足りなくなってしまい、本当に残念である。
